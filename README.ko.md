## 먼저 볼 만한 AI 제품

팀과 함께 만든 작업 중 공개 코드와 데모로 살펴볼 수 있는 프로젝트를 골랐습니다.

- **[vibeDeploy](https://github.com/Two-Weeks-Team/vibeDeploy)** — 앱 아이디어를 발굴·평가하고, 선택한 앱의 코드 생성·검증·DigitalOcean 배포까지 잇습니다. 수상 당시 저장소는 현재 아카이브 상태입니다. [수상작 소개](https://devpost.com/software/vibedeploy-zero-prompt-ai-app-factory-on-digitalocean) · [코드와 구조](https://github.com/Two-Weeks-Team/vibeDeploy#overview)
- **[VibeCat](https://github.com/Two-Weeks-Team/vibeCat)** — 화면 맥락과 음성을 이해하고, 허락을 받은 뒤 데스크톱 작업을 수행하는 macOS AI 동반자입니다. [데모 영상](https://youtu.be/j1zzfoDr7qA)과 [시스템 설계](https://github.com/Two-Weeks-Team/vibeCat/blob/master/docs/FINAL_ARCHITECTURE.md)를 볼 수 있습니다.
- **[Musely](https://github.com/Two-Weeks-Team/musely)** — 개인 AI 에이전트가 만나는 공동의 세계를 실험합니다. 신원 확인, 권한 범위, 지속되는 관계를 다룹니다. [데모 영상](https://youtu.be/rOo4lyCQMik)과 [개발 과정](https://github.com/Two-Weeks-Team/musely/blob/main/docs/BUILD_TIMELINE.md)을 공개했습니다.
- **[Social Seeding](https://github.com/Two-Weeks-Team/social-seeding-v2-public)** — 크리에이터 발굴부터 결과 보고까지 에이전트가 분담하고, 사람이 승인 지점을 관리하는 캠페인 시스템입니다. [ElevenLabs Grant에 선정](https://www.linkedin.com/posts/combba_elevenlabs-socialseeding-aiagents-activity-7473207465124212736-eegr)되었으며, 공개 저장소는 대회 제출 당시의 스냅샷입니다. [데모 영상](https://youtu.be/4SDvNK4cwZs) · [아키텍처](https://github.com/Two-Weeks-Team/social-seeding-v2-public/blob/main/docs/ARCHITECTURE.md)

## 제품을 만드는 개발 환경

- **[Codex Duet](https://github.com/Two-Weeks-Team/codex-duet)** — Orca에서 Codex·Claude 스킬을 골라 설치하고 관리합니다. 원본 버전 고정, 로컬 수정 보존, 파일 소유 기록을 함께 다룹니다. [설치 방법](https://github.com/Two-Weeks-Team/codex-duet#install-in-orca)
- **[Orca Concertante](https://github.com/ComBba/orca-concertante)** — 여러 코딩 에이전트가 목표와 작업 소유권을 공유하며 구현·검증·리뷰를 이어가도록 돕습니다. Orca를 위한 독립 커뮤니티 프로젝트입니다. [시작하기](https://github.com/ComBba/orca-concertante#quick-start) · [검증 범위](https://github.com/ComBba/orca-concertante/blob/main/docs/validation.md)
- **[OpenCode Status HUD](https://github.com/Two-Weeks-Team/opencode-status-hud)** — OpenCode 작업 중 모델, 컨텍스트 사용량, 세션 비용, 제공사 사용량을 한눈에 보여줍니다. [설치 방법](https://github.com/Two-Weeks-Team/opencode-status-hud#install) · [npm](https://www.npmjs.com/package/opencode-status-hud)
